# Código de conduta

Este projeto segue o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate todo mundo com respeito, critique o código e não a pessoa, e não tolere assédio. Problema
de conduta vai para o mantenedor por mensagem privada no GitHub (perfil
[adeiltonpessini](https://github.com/adeiltonpessini)). O mantenedor pode remover comentário, fechar issue e
bloquear quem desrespeitar essas regras.
